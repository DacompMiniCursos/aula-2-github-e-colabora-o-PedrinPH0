#Projeto de SubwaySurfers

#Como Instalar

.Abra a play store ou a app store
.Pesquise por "SubwaySurfers"
.Clique no botão verde com o nome "Instalar"
.Espere ate que chegue a notificação "Aplicativo Instalado"

#Como Usar

.Abra o jogo pela tela inicial do seu telefone
.Clique em jogar
.Comece a partida
.Se mova para cima, baixo, esquerda e direita para desviar dos obstaculos
